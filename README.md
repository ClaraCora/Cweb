# 环境浏览器

一个仅面向个人使用的 iOS 26 多环境浏览器。每个环境使用独立的持久化 WebKit data store、独立 User-Agent 配置和按 Profile 分区的 App 内 Keychain 凭据。

## 当前能力

- 启动后先选择或创建浏览器环境。
- 环境间隔离 Cookie、Web Storage、缓存等 WebKit 网站数据。
- 每个环境独立保存主页、User-Agent 和标识颜色。
- 环境可在编辑页设置分组，列表按分组展示。
- 编辑环境时可保存自动填充账号密码（由应用自身凭据库管理，不调用 iOS 系统自动填充），也可随机生成常见 UA。
- 分组内显示环境余额；签到成功后重新读取页面金额，等待更新后再进入下一个环境。
- HTTPS 站点可按精确 origin 保存并主动填充凭据。
- 凭据展示前使用 Face ID 或设备密码验证。
- 可清理环境的网站数据；删除环境后在下次冷启动清理弃用存储，避免与 WebKit 页面销毁发生冲突。
- 诊断页显示 data store、Cookie 数量，并可按需查询当前公网 IP。
- 可加密导出环境、凭据、代理密码及关联、预设、设置和脚本，解锁预览后新增恢复环境。
- 可选配置 SOCKS5 代理：支持订阅链接、TXT 文件和粘贴文本导入、批量验证和按延迟排名；环境保存当前排名编号，代理列表更新后按新内容使用同一编号。
- 代理可勾选批量导出为 TXT，测速默认使用一次经代理的 TLS 握手及证书校验，不下载网页响应。
- 单个分组支持顺序签到，分组顶部和签到环境顶部都有开始、暂停、停止按钮。
- GitHub Actions 只产出未签名 IPA，不使用任何 Apple 签名材料。

## 工程结构

工程使用 XcodeGen。App 业务源码全部为 Swift；`project.yml`、Info.plist、Asset Catalog 和 GitHub Actions YAML 是 iOS 构建所需配置。

```text
ProfileBrowser/       App 源码与资源
ProfileBrowserTests/  Swift Testing 测试
ProfileBrowserUITests/ 原生 UI 回归与截图
project.yml           XcodeGen 工程描述
.github/workflows/    未签名 IPA 构建
```

## GitHub 构建

1. 将目录放入 GitHub 仓库并使用 `main` 分支。
2. 打开 Actions，运行 `Build unsigned iOS IPA`，或向 `main` 推送相关文件。
3. 构建成功后，到仓库 [Releases](https://github.com/ClaraCora/Cweb/releases) 下载当次构建的 `ProfileBrowser-unsigned-<commit>.ipa`、`SHA256SUMS.txt` 和 `BUILD-INFO.txt`。Actions 运行摘要也会显示下载链接，原生 UI 截图和测试结果一并保存到 Release。可在设置→关于查看并复制版本、构建号和提交。
4. 用 `SHA256SUMS.txt` 校验 IPA。

每次成功构建会发布一个预发布版本，标签格式为 `ios-unsigned-<构建编号>-<重跑次数>`，绑定本次构建的提交。重跑会发布新的版本，构建产物保存在 GitHub Releases，不占用 Actions artifact 存储配额。

未签名 IPA 无法直接安装到普通 iPhone；签名和安装由使用者在 CI 外自行处理。

## 本地限制

Windows 没有 Apple SDK，无法完整编译 SwiftUI/WebKit 代码或运行 iOS Simulator。项目的真实编译与测试关卡是 GitHub Actions 的 macOS 26 runner。

完整架构、边界与验收标准见 [方案.md](方案.md)。

## 代理与设置

代理页使用紧凑列表和常显搜索，数量与测速规则入口合并为一行；每行显示原编号、代号、主机与端口，延迟和状态在右侧，锁定图标紧邻代号。顶部保留“测速”，添加、导入、批量导出和删除集中在“更多”，预设链接默认收起。搜索保留原编号；辅助功能大字体时状态改为纵向排列。批量导出支持全选、仅选可用及手动勾选，按当前显示顺序生成 `Cweb-proxies.txt`，每行一个含凭据的 SOCKS 链接。文件是明文，包含代理账号密码。

TLS 测速使用系统 SOCKS5 隧道，保留认证、目标主机证书校验及禁止直连回退。连接就绪后立即结束，不再重复建连和下载 HTTP 响应；因此延迟数值与旧版不同。关闭 TLS 时仍可使用 SOCKS CONNECT 检测。设置首页只显示外观、签到脚本、测速规则、加密备份和关于入口；脚本编辑在独立页面保存。

分组首页采用“名称列表”：每行显示图标、名称、代号和环境数，整行点击进入；列表上方显示分组总数及环境总数，保留顶部排序、新建和长按菜单。辅助功能大字体时名称可换行，环境数移至下方。

分组内采用“名称随行”布局：代理延迟紧跟环境名称并保持同一行，名称过长时省略，优先完整显示毫秒数；延迟 ≤500 ms 为绿色，>500～2000 ms 为黄色，>2000 ms 为红色，并适配深浅色。余额独立靠右，域名和代理编号放在下一行。辅助功能大字体将余额移至下方，VoiceOver 仍读取完整名称。列表上方的“批量测速”只检测本组引用的代理，共用代理只测一次，直连环境不参与。重新测速期间保留已有的有效延迟及颜色，完成后更新；没有有效结果时显示“未测速”“测速中”或“不可用”。分组测速单独保存结果，不重排编号或删除代理；修改节点、凭据或测速目标后，旧结果会失效。

## 分组顺序签到

进入一个分组，点击顶部“开始”，按当前环境顺序进入签到。签到环境顶部同样显示“开始、暂停、停止”；暂停后点击“开始”继续。返回分组或进入后台会暂停并保存进度；任务未停止时相关环境不能编辑、删除或清理，代理变更也会被阻止。重启后进入原分组可手动恢复当天任务；跨日未完成任务会归档，设置→签到记录可查看最近 30 次结果；手动跳过会单独记录，不能算作签到成功。

任务进行时，导航栏中央显示环境名和域名，其下的紧凑文字栏只显示当前序号、检测状态及开始、暂停、停止；点击左侧进度可展开详细说明、跳过和浏览器工具入口。分组列表顶部也使用同样的文字按钮，可点击进度返回签到页面。底部地址栏与导航工具默认收起，收起后不再占一整行；右上角“填充”保持原位。切换到下个环境时自动收起任务详情和浏览器工具。

页面显示“已完成签到”“今天已完成签到”等明确状态时，保存当日完成记录，显示“更新余额”，从网站重新加载当前页面一次，再读取新页面的金额。读取到连续两次一致的金额即可进入下一个，即使金额没有增加也不再额外等待。整个刷新与读取步骤限时 5 秒，超时或刷新失败时保留原缓存、明确标记更新失败并继续任务。金额显示更新时间；缺少明确余额来源和加载完成规则时标记为待核验，可在签到脚本→网站识别规则中按域名设置选择器。刷新前移除本次签到脚本，避免重复提交或循环刷新。暂停会阻止切换环境，停止会取消读取；普通浏览中的签到成功也会刷新并读取金额。当天已记录完成的环境在任务开始时自动跳过。验证码或未找到入口时停留当前环境，每 5 秒重新检测，验证码由用户手动处理。保持签到页面在前台；本功能不提供后台运行保证。

分组运行使用设置中保存的签到脚本，点击开始会为本次任务启用脚本，不改变普通进入环境时的全局开关。未修改的旧默认模板会自动升级，自定义脚本保持原样，需通过 `window.CwebCheckIn` 上报结果。

验收建议：选择有多个环境的分组，分别检查已完成页面、未找到入口后延迟出现按钮、验证码出现和移除、暂停期间跳转、返回分组再继续、停止后重启及单环境跳过。代理需在真机验证带认证节点、IPv6、超时和无效证书，并导出后核对链接及特殊字符凭据。脚本回归可运行 `node --test scripts/check-in.test.cjs`；Swift Testing 由 macOS 构建环境运行。

## 备份与恢复

新备份导出为 `ProfileBrowser-backup.json`，账号密码仍以加密内容保存。导入也支持旧版无扩展名备份，无需改名：选择文件后，在备份页输入原备份密码，再点“解锁并预览”，确认恢复范围后导入。密码错误可以重试；取消导入或导入成功后会清除本次选择和密码。导入会新增环境，同名分组会合并。v2 包含代理密码及与环境的关联、预设、测速设置、外观和全局脚本；恢复设置和脚本默认关闭。v1 继续兼容，但缺少原代理关联的环境会要求重新选择代理，不能套用目标安装的同号代理。代理冲突及编号变化也会明确阻止联网。网站 Cookie、缓存和任务历史不在备份内。加解密在后台执行，可取消；文件最大 32 MB。

文件选择使用原生文档选择器的复制导入模式，显示文件扩展名；选中后明确关闭选择器，再在备份页读取副本并输入密码。

备份测试覆盖选择回调、取消后重新选择、重复回调处理、JSON 文件读写、固定 v1 备份兼容、密码错误重试、源文件删除后的缓存读取，以及空文件、目录和损坏格式。文件选择器还需要在 iOS 26 真机确认：

1. 导出新备份，确认后缀为 `.json`，再选择并恢复环境及凭据。
2. 直接选择旧无扩展名备份，确认返回备份页并显示文件名和密码输入框。
3. 输入错误密码后改用正确密码；取消后重选；连续导入，确认原有环境仍保留。
4. 选择无效文件时确认出现格式提示；取消文件选择器时确认没有错误提示。

## UA / 环境检测页

根目录的 `ua-diagnostics.php` 是一个可独立部署的 PHP 检测页。将它放到 PHP 网站后直接访问，即可对比服务端收到的 User-Agent、请求头、浏览器参数和能力信息；页面会遮盖 Cookie、Authorization 等敏感请求头，浏览器端数据只在当前页面生成。建议只在自己的站点使用，并按需限制访问权限。

## 日常操作与回归验证

环境仅在首次进入或主页、UA、网站数据存储、代理路径变化时确认；常规点击直接进入。分组内可搜索名称、主页、代理，并筛选今天待签到或已完成。

测速只更新检测结果，不删除代理。“更多→预览规则清理”独立展示删除范围和受影响环境，确认后执行；列表未再次修改前可撤销最近一次删除。分组测速不重排编号；代理页、分组和导出的可用筛选均采用最新检测结果及时间。

密码输入默认遮挡，主动显示后在退入后台时重新隐藏；凭据列表在后台重新锁定，应用切换预览会遮挡内容。

本地脚本回归：`node --test scripts/check-in.test.cjs`。macOS：`xcodegen generate` 后运行 `xcodebuild test -project ProfileBrowser.xcodeproj -scheme ProfileBrowser -destination 'platform=iOS Simulator,name=<iOS 26 设备名称>'`。CI 要求 iOS 26 iPhone 和 iPad 模拟器可用，缺失即失败；原生截图覆盖分组、环境、代理、设置、深浅色、大字体、任务控制与填充位置。Windows 静态语法检查不能替代原生构建或实机验收。逐项实现和验证边界见 [REPAIR_TRACKER.md](REPAIR_TRACKER.md)。
